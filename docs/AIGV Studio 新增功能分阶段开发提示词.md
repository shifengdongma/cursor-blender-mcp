# AIGV Studio 新增功能分阶段开发提示词

## 总体开发目标

请基于现有 AIGV Studio 项目，新增以下两组可视化功能：

1. 多模态 AIGV 创意素材生成工作台；
2. 基于文创 AIGV 素材库的算力调度平台。

本次开发以个人能够完成和维护为前提，重点完成可运行、可点击、可展示业务流程的界面原型。

不要求真实实现以下能力：

- 大语言模型需求解析；
- 文生图模型；
- 图生视频模型；
- 语音克隆；
- AI 图像修复；
- Unity 云渲染；
- Kubernetes；
- 真实 GPU 调度；
- 真实多云平台接入；
- H.265 编码；
- WebRTC 推流；
- HDR 转码；
- USDZ 转换。

以上功能统一使用模拟数据、前端定时器、占位图片、本地 JSON 或简单 Flask 演示接口完成。

------
