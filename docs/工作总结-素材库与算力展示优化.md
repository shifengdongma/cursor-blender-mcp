# 工作总结：素材库与算力展示优化

## 交付结果

1. **素材库统计与文档中心**
   - 四张统计卡片：3D Models、文档、敏感内容库入口、多模态素材库容量。
   - 文档统计合并普通文档与 Prompt 文档，权限范围与旧接口兼容。
   - 统一文档列表支持搜索、日期、排序、分页、来源识别、预览、编辑、删除。
   - 容量卡片使用十进制 TB；实际用量来自数据库 `file_size` 去重汇总，展示模式独立配置。

2. **敏感内容库视图**
   - `/assets?view=sensitive` 复用素材库组件。
   - 标题/副标题切换、统计卡片隐藏、返回素材库。
   - 不新增资产表、不复制数据、不改变可见性或权限。

3. **外部导航与审核 UI**
   - 云算力标题安全外链，新标签页打开，无账号密码或自动登录。
   - 创意生产右侧关键内容审核卡片：关键词管理、当前步骤填入、标记/遮蔽、状态与结果预览、XSS 安全。
   - 纯前端预览，不调用后端审核接口，不影响视频生成/导出。

4. **算力平台展示场景**
   - 运行总览、云渲染、GPU 调度、调度编排、网络监控具备完整可视化。
   - 4 个资源池、4 个在线节点、2 个排队任务；GPU/任务趋势与网络序列稳定一致。
   - 云渲染参考画面优先真实素材，缺失时使用本地 SVG；保留 Three.js。
   - 调度推荐先满足硬约束再评分，返回 top-3 与拒绝原因；状态机仅本地演示。
   - 网络拓扑、链路、告警、事件时间线、播放/暂停/重置和参考故障联动。
   - 实时模式的真实 API 数据优先；缺失显示空态；展示场景不写回真实表、不覆盖官方账单/AI 用量。

- 当前未实现真正的敏感素材标记、审核和访问隔离；敏感内容库视图仅复用现有素材内容。
