- 文档合并：
  - 普通文档：`assets.asset_type=document`，按 owner/tenant/共享权限收敛。
  - Prompt 文档：`prompt_documents` 表。
  - 两表无共享 ID/映射键，按独立记录计数，不做标题/内容去重。

- 容量统计：
  - `GET /api/assets/summary` 新增 `storage`：
    `{used_bytes, quota_bytes, source, actual_used_bytes, actual_quota_bytes, bytes_per_tb, unit}`。
  - 十进制 TB：`1 TB = 1,000,000,000,000 bytes`。
  - 实际占用使用 DB `SUM(file_size)`，按 `file_path` 去重，不做递归磁盘扫描。
  - 当前本地 `.env` 启用 `ASSET_STORAGE_SHOWCASE_MODE=true`，用于展示环境；代码默认关闭。
- Prompt 文档编辑安全：
  - 更新字段白名单：`title/category/content/keywords`。
  - 拒绝 `id/created_at/source_file` 等字段；标题、分类、内容、关键词类型校验。
