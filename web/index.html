    Core Capabilities

    三大核心能力

    将知识库、空间锚点与模型路由收敛为一个更稳定的创作链路。

    知识增强引擎

    结构化 Prompt 六格公式，融合场馆环境、光影词库、材质语义与风格锚点，自动补全专业级视频生成参数。

    • 场馆预设
    • 镜头词库
    • 材质语义
    核心技术

    空间智能锚点

    基于 Blender 的三维空间约束系统，提供白模场景、相机轨迹与 GLB 资产导出，确保视频内容的物理一致性。

    • 相机轨迹
    • 空间约束
    • 资产导出

    多模型路由

    统一接入多类视频模型入口，支持 native、demo-route 与 preview-only 行为边界，便于演示与执行隔离。

    • 多模型接入
    • 智能路由
    • 降级容错
    Model Router

    支持的视频生成模型

    前端展示多种模型入口，后端按 route mode 与执行通道完成分发。

    Prompt Formula

    黄金六格 Prompt 公式

    用更清晰的六模块结构组织镜头、主体、动态、环境、光影与风格。

    01

    镜头语言

    先锁定三维坐标系与观众视角，避免画面退化为静帧或透视失真。

    02

    主体材质

    用 velvet、patina、mahogany 等物理词汇描述核心对象与触感。

    03

    动态行为

    通过尘埃、烟雾、反射锚定时间流逝，增强场景生命感。

    04

    环境空间

    定义大剧院、白立方画廊、古典博物馆等物理容器与建筑逻辑。

    05

    光影氛围

    通过体积光、明暗对照、月光蓝建立情绪和空间深度。

    06

    风格锚点

    用电影级风格与负向词控制整体完成度和稳定性。

    Asset Library

    空间资产库

    基于三维扫描与 UE 精修的空间白模锚点，可与工作台联动选择。

    Project Metrics

    项目指标

    用于展示知识库规模、资产沉淀与工作流能力边界。
