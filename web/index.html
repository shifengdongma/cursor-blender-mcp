    Core Capabilities

    三大核心能力

    将知识库、空间锚点与模型路由收敛为一个更稳定的创作链路。

    知识增强引擎

    结构化 Prompt 六格公式，融合场馆环境、光影词库、材质语义与风格锚点，自动补全专业级视频生成参数。

    • 场馆预设
    • 镜头词库
    • 材质语义
    空间预演

    空间智能锚点

    基于 Blender 的白模场景与相机轨迹，为 Prompt 提供空间约束和预演参考；空间锚点不作为视频模型首帧。

    • 相机轨迹
    • 白模预演
    • 空间约束

    多模型路由

    统一接入火山方舟 Seedance、Atlas Cloud 与 Luma 等真实生成通道，并按凭据和模型能力展示可用状态。

    • 真实通道
    • 能力约束
    • 状态反馈
    Model Router

    支持的视频生成模型

    来自真实模型注册表；可用性表示凭据已配置，模型开通状态以生成结果为准。

    Prompt Formula

    黄金六格 Prompt 公式

    用更清晰的六模块结构组织镜头、主体、动态、环境、光影与风格。

    01

    镜头语言

    先锁定三维坐标系与观众视角，避免画面退化为静帧或透视失真。

    02

    主体材质

    用 velvet、patina、mahogany 等物理词汇描述核心对象与触感。

    03

    动态行为

    通过尘埃、烟雾、反射锚定时间流逝，增强场景生命感。

    04

    环境空间

    定义大剧院、白立方画廊、古典博物馆等物理容器与建筑逻辑。

    05

    光影氛围

    通过体积光、明暗对照、月光蓝建立情绪和空间深度。

    06

    风格锚点

    用电影级风格与负向词控制整体完成度和稳定性。
